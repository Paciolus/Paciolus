# Liberation Fonts 2.1.5

Embedded in every PDF Paciolus generates (Sprint 885, review OUT-25): they cover
Latin with accents, Greek and Cyrillic, and are metric-compatible with Times,
Helvetica and Courier, so layouts did not move when they replaced the standard
PDF fonts. Registered by `backend/shared/pdf_fonts.py`.

- Source: https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5
  (`liberation-fonts-ttf-2.1.5.tar.gz`, SHA-256
  `7191c669bf38899f73a2094ed00f7b800553364f90e2637010a69c0e268f25d0`)
- Licence: SIL Open Font License 1.1 — see `LICENSE` (shipped with the fonts,
  including in the Docker image).
- Chinese, Japanese and Korean are not covered; see `tasks/todo.md` (Deferred Items).
